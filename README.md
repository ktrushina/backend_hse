# Ad Moderation API

Учебный HTTP-сервис на FastAPI, который определяет, нарушает ли объявление простое правило модерации.

## Правило модерации

- Если продавец подтверждён, объявление проходит проверку при любом допустимом количестве фотографий.
- Если продавец не подтверждён, для прохождения проверки нужна хотя бы одна фотография.

## Эндпоинты

### `GET /`

Возвращает `{"message": "Hello World"}`.

### `POST /predict`

Принимает JSON. Все поля обязательны, типы проверяются строго.

| Поле | Тип | Описание |
| --- | --- | --- |
| `seller_id` | `int` | Идентификатор продавца |
| `is_verified_seller` | `bool` | Подтверждён ли продавец |
| `item_id` | `int` | Идентификатор объявления |
| `name` | `str` | Название объявления |
| `description` | `str` | Описание объявления |
| `category` | `int` | Идентификатор категории |
| `images_qty` | `int` | Количество фотографий, от 0 |

Пример запроса:

```json
{
  "seller_id": 10,
  "is_verified_seller": false,
  "item_id": 20,
  "name": "Стул",
  "description": "Деревянный стул",
  "category": 3,
  "images_qty": 0
}
```

В этом примере ответ — `true`, потому что продавец не подтверждён и у объявления нет фотографий.

| HTTP-код | Ответ |
| --- | --- |
| `200` | Одно JSON-значение: `true` — есть нарушение, `false` — нарушений нет. |
| `400` | Запрос не прошёл валидацию. Ответ содержит описание ошибок. |
| `500` | Во время предсказания произошла внутренняя ошибка. |

## Структура проекта

- `main.py` — создаёт приложение FastAPI, подключает роутер и обрабатывает ошибки валидации.
- `routers/predict.py` — принимает HTTP-запрос и вызывает сервис.
- `schemas/predict.py` — задаёт обязательные поля и проверяет их типы.
- `services/predict.py` — применяет правило модерации и возвращает результат.
- `repositories/prediction.py` — возвращает минимальное число фотографий для неподтверждённого продавца. В текущей реализации это `1`.

## Установка и запуск

Из корневой папки проекта на macOS или Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
fastapi dev
```

Swagger UI доступен по адресу <http://127.0.0.1:8000/docs>.

## Тесты

Из корневой папки проекта с активированным `.venv`:

```bash
python -m pytest -q
```

- `tests/test_predict.py` проверяет эндпоинты через `TestClient`: оба результата модерации, неверные типы и отсутствующие поля, некорректное тело запроса и обработку сбоя сервиса.
- `tests/test_prediction_service.py` проверяет правило модерации напрямую. Подставной репозиторий задаёт минимум в две фотографии, чтобы проверить, что сервис использует значение из репозитория.
